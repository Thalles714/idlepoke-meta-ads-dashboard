# Dashboard IdlePoke / Meta Ads

Dashboard público de acompanhamento da aquisição do IdlePoke.

O arquivo `index.html` é gerado localmente a partir da planilha oficial. Ele contém os dados consolidados, estilos, scripts, imagens e fonte necessários para funcionar sem dependências externas.

Planilhas, exports brutos do Meta Ads e credenciais não fazem parte deste repositório.
